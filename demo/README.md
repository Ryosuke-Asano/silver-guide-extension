# 横浜市立図書館・入力検証用モック

横浜市立図書館の実際の利用者情報仮登録フォームと利用申込書を参考にしたローカルのデモです。Silver Guideのスタイル・部品・ランタイムは読み込まず、ブラウザーに導入した拡張機能の補助を検証します。

## 起動

拡張を含むデモは、依存パッケージのインストール後、リポジトリのルートで `npm run dev:demo` を実行します。Windows・macOS・LinuxのGoogle Chromeで、拡張のビルド・自動読み込み・デモサーバーの起動をまとめて行い、<http://127.0.0.1:4287/> を開きます。終了はCtrl+C、またはデモ用Chromeの全ウィンドウを閉じます。[詳しい手順](../docs/demo-usability.md)を参照してください。

モックだけを起動する場合は、リポジトリのルートから `npm run demo`、またはこのフォルダーから `node server.mjs` を実行します。この方法は追加の依存パッケージ不要で、拡張を手動で読み込みます。

- フォーム：<http://127.0.0.1:4187/>
- PDFへの入力（E-mailの直下）：<http://127.0.0.1:4187/#pdf-fields>
- 架空の入力例・チェック項目・出典：<http://127.0.0.1:4187/guide.html>

HTTPサーバーは127.0.0.1だけで待ち受けます。`SILVERGUIDE_DEMO_PORT`で別ポートも指定できます。HTMLを直接開かず、HTTPを使用してください。旧 `/pdf.html` はフォーム内のPDF欄へ移動します。

## 操作

1. 名前、生年月日、住所、電話番号などを入力します。
2. 対応するSilver Guideを有効にすると、E-mailの下の原本PDFリンクの横へ、拡張が「Silver Guideで記入」を表示します。ページに専用の連携コードはありません。
3. ボタンを押すと原本PDFと添付先を引き継いで記入画面が開き、氏名から入力できます。
4. 「入力を完了」で記入済みPDFを戻します。このデモの拡張内アダプターは、通常の内容確認・模擬完了を操作します。必須値が不足する場合はPDFを保持してエラーへ戻ります。

この機能のPDF検出・取り込み・添付は、許可済みの通常サイトでも使えます。通常サイトの送信操作は選択制で、サイトの受理は別途確認します。アダプターと制約は `docs/decisions/pdf-web-workflow.md` を参照してください。

拡張なしでも、原本のダウンロード・PDFのファイル選択・内容確認・模擬完了を使えます。入力内容とファイルは送信・永続保存しません。リセットまたは選択解除で添付をクリアします。

## 支援なしで試す

`npm run dev:demo -- --manual` で、拡張を読み込まないChromeからフォームとPDF入力を試せます。入力画面を開くとすぐに記入できます。原本PDFをダウンロードし、標準のPDF編集アプリで記入・保存してから添付し、内容確認・模擬完了へ進みます。

サーバー不要の同封デモは、開始画面で「支援なし」または「Silver Guideあり」を選びます。[同封デモの手順](../docs/bundled-comparison-demo.md)を参照してください。

## 入力仕様

名前と名前カタカナは各1欄、上限512文字。入力中の空白・文字を自動変換しません。カナ欄は全角カタカナ・長音符・英字・空白を許容し、確認時に形式を検証します。電話は3分割の通常のテキスト欄で、各4桁以内の半角数字、後半2欄は合計7桁以上。市外局番の045は省略できます。自動補完しません。住所検索は220-0032、231-0005、222-0033のローカル見本のみです。

## PDF資料

`assets/library-application-original.pdf` は取得した公式PDFと同一です。A5・1ページで、元のPDFにAcroFormの入力欄はありません。

SHA-256: `cd6ad4a7291340abcc8c70b94c191367ce1b9fa4c01a604889c5c9a4d6b01ff7`

`assets/library-application-fillable.pdf` は非公式の比較用派生物です。原本に姓・名、各フリガナ、郵便番号、住所、自宅・携帯電話の透明なAcroForm欄13個を追加しています。空欄状態は120dpiの描画で原本と全ピクセル一致し、日本語・数字を記入した値と描画を確認済みです。出典・位置は `assets/library-application-source.json` にあります。

2026年10月28日のSilver Guide改善版では、原本PDFのSHA-256一致時に、デモ用14項目を表示します。最初は「手続の内容」の6つのチェック欄です。左の選択欄とPDF上の枠から付け外しできます。その後は氏名から「戻る／次へ」で順に進み、途中保存できます。生年月日などは14項目に含みません。チェック位置の追加設定は `assets/library-application-source.json` の `extension_overlay` に記録しています。入力欄追加版など、原本と異なるPDFは通常の推定を使うため、質問数が14とは限りません。これは原本の自動認識精度の測定結果ではありません。

## 拡張機能の辞書

拡張機能の辞書を22語から86語へ拡充しています。図書館の登録条件、氏名・カナ・電話の書式、PDF・添付・アップロード・保存などの説明を追加しました。説明文から確認でき、入力欄やラベルそのものには辞書を重ねません。辞書のソースはリポジトリ側にあり、この静的モックには同梱していません。

## 検証

入力エラー、確認・修正・条件分岐、メール条件、模擬完了、リセット、住所検索、安全な文字表示、PDFの選択と解除を確認します。OSの日本語変換・確定は、文字列を自動入力する確認と分けて実際に試してください。

フォームと添付操作は実HTMLを使った85項目、辞書関連は75テストを確認済みです。ChromeとFloorpでE-mail直下の配置・追加辞書の表示を確認し、Floorpでは実際のファイル選択ダイアログからPDFを選択・解除しています。アップロード時の確認はサイズ・PDFのヘッダーと終端を対象とする簡易検証です。
