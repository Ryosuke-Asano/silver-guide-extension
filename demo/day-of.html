SILVER GUIDE · 当日の進行用

当日は、この3ステップで。

準備 → 1人ずつ比較 → 記録を持ち帰る。
両方式で同じフォームと原本PDFを使います。サーバーの起動やWi-Fi接続は不要です。

1　準備最初に1回2　比較参加者ごと3　保存返却する前

1端末に入れて、記録せずに練習

  1. 配布ZIPを展開し、中の Chrome フォルダーを端末に保存します。
  2. Chromeのアドレス欄へ chrome://extensions と入力。「デベロッパーモード」をオン →「パッケージ化されていない拡張機能を読み込む」→ Chrome フォルダーを選びます。
  3. 「比較デモを始める」が開きます。閉じたときは、chrome://extensions でSilver Guideの「詳細」→「拡張機能のオプション」から開きます。
  4. 開始画面の「記録せずに練習する」から、両方式を1回ずつ試します。「練習（記録しません）」の表示を確認。手作業でもPDFに日本語とチェックを入れ、保存・添付できるか確かめます。終了後は「練習を終えて開始画面へ」。

Chromebookが2台使える：同じZIPを両方に入れます。
拡張を入れられない／PDF編集ができない：持参Macで両方式を実施します。端末変更前後の時間は、同じ比較の組にしません。

準備OK：両方式でPDFを記入・添付し、「入力の検証が完了しました」まで進める。

2同じ参加者が、両方式を1回ずつ

  1. 開始画面で参加者番号を設定し、方式を選びます。同じ人は2台でも同じ番号、次の人には別の番号を使います。
  2. 「入力をクリアして計測開始」を押し、「計測中：参加者 …」を確認してから入力します。下の架空の入力カードを両方式で使います。
  3. 先にフォームを入力してから、PDFへ進みます。
    支援なし：「図書館利用申込書.pdf をダウンロード」→ PDF編集 → 保存 →「記入済み申込書のアップロード」→「入力内容を確認する」→「この内容で完了（模擬）」。
    Silver Guideあり：「Silver Guideで記入」→ 14項目を入力 →「入力を完了」。自動で添付・模擬完了まで進みます。エラーが出たら直して完了まで進みます。
  4. 完了画面の「記録しました：1周 … ／ PDF作業 …」を確認。「同じ参加者で…へ」から残りの方式へ進みます（番号は引き継がれます）。両方終えたら「次の参加者・開始画面へ」。

奇数の参加者　支援なし → あり偶数の参加者　あり → 支援なし

1人分OK：「計測結果・CSV」で、その参加者に両方式の完了記録とPDF作業時間がある。

3各端末で、2種類の記録を保存

  1. 「計測結果・CSV」で「CSVを保存」と「端末間で移す記録を保存」を両方押します。CSVは閲覧・集計用、JSONは記録の統合・バックアップ用です。
  2. 貸出端末のダウンロードフォルダーだけに残さず、USB等で持参Macなど持ち帰れる場所へコピーします。端末ごとにフォルダーを分けると混ざりません。
  3. 2台分をまとめるときは、Mac等の結果画面で「他の端末の記録を取り込む」から各JSONを選びます。両方式の記録が表示されたら、統合後のCSVとJSONも保存します。

返却前に確認：使用した全端末のCSVとJSONを持ち帰れる場所へコピー済み。確認が済むまで拡張やChromeプロフィールを削除しません。

手作業のPDF：短い手順

Chromebook：「ファイル」で保存したPDFを開く → ギャラリーの「テキスト」で文字を置く → ペンで新規登録の□にチェック →「保存」。
Mac：保存したPDFを「プレビュー」で開く → マークアップの「テキスト」で文字を置く → スケッチで新規登録の□にチェック →「ファイル」→「保存」。

保存したPDFを開き直し、文字とチェックが残っていることを確認して、フォームに添付します。毎回同じ編集ソフトを使い、ソフト名を進行者がメモします。

PDF編集の操作根拠：Google・ギャラリーの公式手順 ／ Apple・プレビューの公式手順。貸出Chromebook実機での動作は、開始前の練習で確認します。

困ったときだけ開く

「支援なし」にするには？

開始画面で「支援なし」を選びます。拡張そのものは無効にしません。デモも拡張に入っているためです。比較するのは、同じ拡張内での支援あり／支援なしです。

Chromeフォルダーを選べない／読み込めない

ZIPを展開し、manifest.json が直接入っているChromeフォルダーを選びます。「デベロッパーモード」が管理者に制限されている場合は、持参Macへ切り替えます。Chromebook本体の開発者モードへ変更する作業はありません。

入力欄を押せない／PDFなしで先へ進めない

本番は「入力をクリアして計測開始」を押すと入力できます。計測中は記入済みPDFの添付が必要です。操作だけ試す場合は開始画面の「記録せずに練習する」を使います。

途中でやり直したい／間違った参加者番号で始めた

「計測を中止」を押して記録を確認し、正しい番号で新しく開始します。中止の回は完了時間の集計に入りません。PDF記入画面だけ閉じても、元のフォームの計測は続くため、元のフォームで中止してください。

「記録しました」が出ない

元のフォーム上部の計測表示を確認します。練習は記録されません。本番で「保存を再試行」が出たらそのボタンを押し、保存を確認するまで閉じません。突然終了した回は完了扱いにしません。

PDF作業が「比較対象外」になった

計測開始後にフォームのPDFダウンロード、または「Silver Guideで記入」から進み、PDFを添付して完了してください。別の場所からPDFを開くと、作業の開始時点を記録できません。

ボタンが画面の下に隠れる

ウィンドウを最大化し、ページを下へスクロールします。Chromeの拡大率が大きい場合は、Chromebookでは Ctrl＋0、Macでは ⌘＋0 で標準に戻します。

同じ人を2台に分けて測るとき

同じ参加者番号を使い、できれば同じOS同士で両方式を実施します。Macの「あり」とChromebookの「なし」は、端末の影響も混ざるため1組として集計しません。可能なら、どちらの端末でどの方式を行うかも交互にします。

何の時間を比較している？

1周は計測開始から模擬完了まで。PDF作業は原本を開く操作から記入済みPDFの添付確認までです。「読込・準備・出力」はSilver Guide内部の処理時間で、PDF作業時間の内訳です。結果画面では、同じ参加者・同じOSの両方式を組にして差を表示します。

横浜市の公式サービスではない検証用デモです。入力内容・PDFは外部へ送信しません。計測記録には参加者番号・方式・時間などが残ります。通常のChromeプロフィールを使い、シークレットやゲストモードは避けてください。

この手順書はファイルを開くだけで読めます。印刷：Chromebookは Ctrl＋P、Macは ⌘＋P。折りたたみの「困ったとき」は画面で確認できます。
