# 比較デモ同封版の使い方

`codex/bundled-comparison-demo` はデモ専用ブランチです。通常版の `master` には反映しません。フォーム、同じ原本PDF、Silver Guideの補助、数値の記録・集計を拡張に同封し、サーバーやNode.js、Wi-Fi接続なしで実施します。

## 端末へ入れる

1. 配布ZIPを展開し、`Chrome` フォルダー全体を端末のダウンロード等へ保存します。ZIPの中から直接読み込まず、フォルダーを取り出します。
2. Chromeで `chrome://extensions` を開き、「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` が入っている **Chromeフォルダー**を選びます。
4. 「比較デモを始める」が開きます。閉じた場合は、拡張アイコン、または拡張の詳細の「拡張機能のオプション」から開けます。

Chromebook2台では両方に同じパッケージを読み込みます。学校・貸出端末で開発者モードや拡張の導入を管理者が禁止している場合、この方法では起動できません。その場合は持参Macで同じパッケージを使います。端末管理の制限を回避する設定変更は不要です。

これは「拡張をインストールした状態での支援あり／支援なし」の比較です。支援なしのフォームでは、入力ヒント・単語ポップアップ・文章選択の連携・PDF記入ボタンを起動しません。拡張そのものを無効にすると、同封デモも開けなくなります。拡張を本当に入れない比較は、従来の `npm run dev:demo -- --manual` をMacで使います。

## 当日の進め方

1. まず各端末で1回練習します。支援なしで原本PDFをダウンロードし、普段のPDF編集ソフトで日本語とチェックを入れ、保存して添付できるか確認します。実際に使ったソフト名をメモします。
2. 入口で「支援なし」または「Silver Guideあり」を選びます。参加者番号を設定し、「入力をクリアして計測開始」を押します。両方式で同じ参加者番号を使います。
3. 「比較する入力例と手順」にある架空の情報でフォームとPDFを入力します。原本PDFの新規登録、氏名、フリガナ、郵便番号、住所、自宅電話、携帯電話の14項目を両方式で対象にします。生年月日・勤務先など、Silver Guideの14項目にないPDF欄は両方式とも対象外です。
4. 支援なしは原本をダウンロードして通常のPDF編集ソフトで記入・保存・添付し、確認・模擬完了まで進みます。支援ありは「Silver Guideで記入」から進み、「入力を完了」で自動添付・模擬完了まで進みます。基本情報に不備があれば、その修正も時間に含みます。
5. 1人目は支援なしから、2人目は支援ありからというように実施順を交互にします。2台でも同じ人に両方式を実施してもらいます。可能なら方式と端末の組み合わせも入れ替えます。Macの記録とChromeOSの記録は、同じ参加者でも同一の組にしません。
6. 「計測結果・CSV」で記録を確認します。1周とPDF作業の平均・中央値、同じ参加者・同じOSの時間差を表示します。実際の人の結果が集まるまでは、改善率を実験結果として扱いません。

1周は「計測開始→模擬完了」、PDF作業は「原本のダウンロード／Silver Guideで記入→記入済みPDFの添付形式確認」です。拡張のPDF読込・準備・出力は、PDF作業に含まれる処理時間の内訳です。PDFなし・開始不明・未完了の回は集計対象外です。ブラウザーが突然終了して保存できなかった回は「計測中・未完了」として残り、完了扱いにしません。保存失敗時の再試行では、最初の終点の時間を維持します。

## 2台の記録をまとめる

各端末の結果画面で「端末間で移す記録を保存」を押し、`silver-guide-records.json` をUSB等で片方の端末へ移します。その端末の結果画面で「他の端末の記録を取り込む」を選びます。同じ記録を再度取り込んでも、二重に加算しません。全員の参加者番号は端末間で統一してください。CSVは移行用の形式ではなく、集計後の閲覧・分析用です。

記録は同じChromeプロフィールのIndexedDBに保存します。Chromeを閉じても残りますが、**貸出端末の返却・拡張の削除・プロフィールの削除前に、CSVと移行用JSONの両方を保存してください。** 通常モードを使い、シークレットウィンドウや毎回削除されるゲストプロフィールは使いません。氏名・住所・フォームの値・選択文章・PDF・ファイル名は記録しません。移行用ファイルも数値と方式・参加者番号・日時・OS種別・ビルドIDだけです。

## 開発時のビルドと検証

既存の依存パッケージを入れた環境で `npm run build:chromium` を実行すると、`dist-chromium/demo/` を含む拡張を生成します。実行時はビルド環境を持ち込む必要はありません。配布時は `dist-chromium/` 全体を `Chrome/` としてZIPにします。開発用の鍵・回答・計測ファイルは含めません。

通常の `npm run dev:demo` と拡張を読み込まない `--manual` も引き続き使えます。HTTP(S)上の汎用PDF検出・添付と、同封デモの拡張ページの連携経路は区別し、他の拡張のページや支援なしのページを連携先として受け付けません。

検証はインストール済みGoogle Chromeと、HTTP(S)リクエストを遮断した独立プロフィールで行います。支援ありの文章説明・14項目のPDF記入・自動添付と模擬完了、支援なしの原本ダウンロードと添付・模擬完了、Chrome再起動後の記録保持、別プロフィールへの移行・重複防止・不正ファイル拒否を自動試験で確認します。手作業側の自動試験は添付経路を確認し、人の入力時間やOS標準PDF編集ソフトの操作を代用しません。ChromeOS実機と貸出端末の管理ポリシーは未確認です。
