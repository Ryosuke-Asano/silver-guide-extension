# Silver Guide 3.0.0

確定日：2026-10-20 JST。**三機能と画面構成を採用済み。** この資料群は実装の基準であり、コード実装・実機確認・公開判定の完了を示さない。

## 採用した構成

| 機能 | 画面と操作 |
| --- | --- |
| フォーム補助 | 元の入力欄にフォーカスすると上側に小さな Tooltip。上に置けない場合だけ下側。元の欄へ直接入力し、追加ボタン・別入力欄・反映工程を作らない |
| 文章の解説 | 本文の下線語をクリックすると、近くに元語と短い説明のポップアップ。操作は閉じる一つ。長い文章を範囲選択する解説はサイドパネルで補助 |
| PDF | 専用タブの左に一問、右に記入プレビュー。入力後はPDF上へ自動反映し、戻る／次へで記入、最後の同じ位置のボタンから PDF を保存する |

独自のパスワード保護・保管庫・下書き管理・履歴・バックアップ・登録情報・別 Reader・読み上げ・手続きチェックリスト・更新管理画面は削除する。代わりの平文自動保存は追加しない。

過去の「ボタンが多く、PC 操作に慣れた本人でも間違えた」を最重要の教訓とし、初見で入口・入力場所・次の操作・戻り先が分かることを優先する。

## 実装の順番

0. 未コミット・未追跡を含む現在のソースと必要資産を保全する。
1. ブラウザーの権限・起動と、三つの画面の最小動作を確認する。
2. 元フォームの上側 Tooltip を仕上げる。
3. 本文の辞書語の下線とページ内ポップアップを仕上げ、文章選択のサイドパネルを補助として保つ。
4. PDF を開き、日本語を記入して実際に保存する最短経路を仕上げる。
5. PDF の必要な欄修正・OCR などを接続する。
6. 旧保管庫・別入力画面・反映処理・旧ドックなど、不要な機能と依存の除去を完了する。
7. 対象ブラウザーの実機・初見操作・配布物を検証する。

各工程の完了条件は [実装作業順](implementation-plan.md)、現在の進捗と検証は [実装状況](implementation-status.md) を参照する。記入プレビューを含む今回版の自動試験・両ビルド・実ブラウザーでの確認は、以前の下線語ポップアップや実IME・標準PDF保存先ダイアログの検証と分けて記録する。対象利用者の初見評価・他OS・署名一般配布は未実施として残す。
