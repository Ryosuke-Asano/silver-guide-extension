採用モックとの比較では、白地・青緑・短い上側Tooltip、解説の原文と説明、PDFの左右配置と固定した前後ボタンを継承した。PDFの通知欄は処理状態で下部ボタンが飛ばないよう高さを確保し、原本は編集中の回答を重ねず元PDFを示す。保存後の再読込で成果物を確認する。パネルの幅・左右・閉じる操作はブラウザーに従う。

## ブラウザーと対応範囲

Geckoは `sidebar_action`、Chromiumは `side_panel` とネイティブのアイコン開閉を使う。manifestの最低版はGecko 140・Chromium 122。選択の返信は同期コールバックを使い、Chrome148から段階導入されるlistenerのPromise返信へ依存しない（[Chrome公式のメッセージ仕様](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)）。実測はWindowsのFloorp 12.20.2／Gecko 158.0.1と検証用Chromiumに限定し、最低版や他OSの実証とはしない。

フォーム補助は許可済みHTTP(S)の最上位文書で動作する。iframe内やブラウザー設定画面等は対象外。拒否・復許可はブラウザー標準UIを使い、アイコン操作でブラウザーが与える一時的な `activeTab` 許可と全サイトへの恒久許可を分ける。

PDFはファイル選択・ドラッグ＆ドロップを採用する。表示中PDFの自動取得・URL入力画面は提供せず、パネルの「PDFを開く」から専用タブのファイル選択へ案内する。
