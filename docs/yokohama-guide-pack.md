# 横浜市ガイドパック（住民票オンライン申請）

レビュー日: 2026-09-16

## 対象とする公開ページ

- 横浜市: 「住民票の写し・住民票記載事項証明書をオンライン申請する」
  - `https://www.city.yokohama.lg.jp/kurashi/koseki-zei-hoken/todokede/koseki-juminhyo/shoumei/jyuminhyou/online.html`
- 横浜市電子申請・届出システム: ホーム
  - `https://shinsei.city.yokohama.lg.jp/cu/141003/ea/residents/portal/home`

URL と公開見出しの両方が一致したときだけ、詳細な案内を表示する。見出しが改版された場合は、一般的な用語解説だけに戻る。

## 表示する内容

- 利用できる方、マイナンバーカード、署名用電子証明書、暗証番号、手数料、受け取りまでの日数の事前確認
- 横浜市電子申請・届出システム、動作環境、よくある質問への公式リンク
- ローカル辞書による「電子申請」「電子署名」などのやさしい説明

## 表示しない・行わないこと

- ログイン ID、パスワード、暗証番号、マイナンバー、フォーム入力値の読取・保存・送信・表示
- 申請の自動送信、電子署名、決済、外部サービスへのログイン

横浜市の公開ページに記載された案内を、利用者が理解しやすい順に表示するだけであり、手続きの可否や行政上の判断を行わない。
