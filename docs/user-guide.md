# Silver Guide 3.0.0 使い方

Silver Guide は、フォーム入力の補助、文章の解説、PDFへの記入を手伝います。3.0.0では、この三つに機能を絞っています。導入方法は [README](../README.md) を参照してください。

この版は未署名の開発版です。正式な対応環境や一般公開の判定は、[3.0.0の実装計画](specs/3.0.0/implementation-plan.md)で確認してください。

## 最初にサイトへのアクセスを許可する

フォームの自動補助と文章の解説には、対象サイトへのアクセス許可が必要です。許可・拒否・取り消しは、ブラウザー標準の拡張機能の設定で行います。Silver Guide独自の設定画面やパスワード登録はありません。

Floorpでは、アドオンマネージャーでSilver Guideを開き、「権限とデータ」からウェブサイトへのアクセスを変更できます。ブラウザーや版によって、設定の名前・場所は異なります。許可していないサイトでは、自動の補助は出ません。

拡張アイコンを押すと、そのタブへの一時的なアクセスが与えられる場合があります。これはサイトへの継続的な許可とは別です。ページ移動後も自動でフォーム補助を使う場合は、ブラウザーのサイトアクセス設定を確認してください。ブラウザー内部の設定ページなど、アクセスできないページもあります。

## フォーム：欄へそのまま入力する

1. 元サイトの入力欄をクリックするか、Tabキーで移動します。サイドパネルを開く必要はありません。
2. 入力形式が分かる欄には、上側に小さなTooltipが出ます。たとえばカタカナ指定のフリガナ欄には「カタカナで入力します。」「例：ヤマダ ハナコ」と表示します。元サイトの指定がある場合は、その指定に従います。
3. 元の欄へ直接入力します。次の欄へ移ると補助も切り替わります。Shift+Tabでも戻れます。
4. 補助を閉じるときはEscapeを押すか、欄からフォーカスを外します。確認・送信は元サイトのボタンを使います。

上側に置くと欄名などを隠す場合は、下側に出します。上下とも場所がなければ、入力を優先して表示を控えます。元サイトに説明やエラーがある場合も、そちらを優先します。日本語の変換中は、候補を妨げないよう補助を一時的に隠します。

補助用の別入力欄や「フォームに反映」ボタンはありません。フリガナの自動変換や値の上書きは行いません。フォーム補助だけで送信操作を行うことはありません。PDFの連携操作では、選択した添付欄へ記入済みPDFを戻し、希望した場合は表示したフォーム操作も行えます。パスワード・認証情報などの欄や、形式が分からない欄へ、推測した記入方法を表示しません。

## 文章：下線の単語をクリックして読む

1. 元ページの本文にある、下線の付いた単語をクリックします。サイドパネルを開く必要はありません。
2. 単語の近くに、元の言葉と短い説明のポップアップが出ます。
3. 「閉じる」、Escape、ポップアップの外をクリックする操作で閉じます。別の下線語を押すと説明が切り替わります。

キーボードでは、Tabで下線語へ移動してEnterまたはSpaceで開けます。同梱辞書に説明のある本文の言葉が対象です。元からあるリンクやボタン、フォーム欄とラベル、編集領域、コードには解説用の下線を追加しません。フォーム内でも、公開の本文には下線が付くことがあります。

### 長い文章を横で読む（補助）

1. ツールバーのSilver Guideアイコンを押し、解説用サイドパネルを開きます。
2. 元ページで、説明したい言葉や文章を選びます。選んだ原文と説明がパネルに表示されます。
3. 別の文章を選ぶと、説明が切り替わります。毎回「解説する」を押す必要はありません。
4. 閉じるときは、ブラウザーのサイドパネルの閉じる操作を使います。元フォームの入力値は変わりません。

単語を選ぶと、元の言葉と説明文を表示します。文章では、条件やすることを「文章の説明」に先に表示し、単語ごとの説明は「言葉の意味」から開けます。「原文を見る」から、選択した文章をそのまま確認できます。別の文章を選ぶと、説明の先頭へ戻り、原文と単語の一覧を折りたたみます。パネル内のロゴ・ページ名・重複する見出しは表示しません。

単語ポップアップは同梱辞書、サイドパネルは同梱辞書と選んだ原文に基づきます。サイドパネルで一部だけ説明できた場合や、説明が見つからない場合は、その状態を表示します。条件・数字・例外や制度の判断は原文でも確認してください。入力欄や編集領域の中身は、文章解説の対象にしません。

パネルの左右・幅はブラウザーの設定に従います。「PDFを開く」は右上の「⋯」（その他の操作）にあります。

## PDF：原本を見ながら一項目ずつ記入する

1. サイドパネル右上の「⋯」から「PDFを開く」で専用タブを開き、ファイルを選びます。専用タブへPDFをドラッグしても開けます。ウェブページにあるPDFリンクは、下記の直接記入も使えます。
2. 読み取りが終わると、左に一つの質問、右に記入プレビューが表示されます。狭い画面では縦に並びます。読み取り中は「中止」で処理を止められます。
3. 回答すると、少し待ってPDF上へ仮想的に書き込まれます。日本語の変換中は更新を待ち、確定後に反映します。「次へ」「戻る」で移動しても全回答が残り、変更・削除もプレビューへ反映されます。ページ・倍率はプレビュー側で操作できます。
4. 項目名や記入場所が違う場合だけ「この項目を直す」を開きます。「修正を採用」または「取消」で元の質問へ戻れます。欄が見つからない場合は「入力欄を追加」から指定できます。
5. 「ここまでの入力を保存」から途中でも保存できます。最後の「次へ」も、同じ場所の「PDFを保存」に変わります。作成と出力検査の後、ブラウザー標準の保存先ダイアログで場所と名前を選びます。未入力項目がある場合は、その数を表示します。
6. 保存したファイルを開き、文字・選択内容・位置を確認してください。保存の失敗や取消があっても、開いている作業タブの回答は残ります。

上部は短いヘッダーにまとめています。ファイル名の全文、連携元のURL、デモ用の記入範囲は、右上の「書類の詳細」から確認できます。単独で開いたPDFを切り替える「別のPDFを開く」も、この中にあります。フォームと連携する場合は、添付先と入力完了後の操作をヘッダーの直下に表示します。

「戻る／次へ」は質問の下に表示します。高さの小さいPC画面では、入力部分をスクロールでき、移動ボタンの場所を確保します。狭い幅では、ページを縦にスクロールして入力欄とプレビューを確認できます。

チェック欄は、左の選択欄とPDF上の青緑の枠から付け外しできます。複数の選択がある質問は一覧で表示します。プレビューで選択を変えても他の回答は残り、保存・添付にも同じ選択が反映されます。

保存先ダイアログを取り消した場合は、未保存であることを表示します。回答を直す必要がなければ、同じ「PDFを保存」から再試行できます。ダイアログで保存先を考えている間も、作業タブの回答を保持します。

受付上限は100MiB・100ページです。文字のあるPDF・入力欄付きPDF・画像の文字認識を扱いますが、すべての書類を正しく読み取れる保証はありません。読み取れないページや記入できない理由が表示された場合は、その案内と原本を確認してください。

元PDFを開くためにパスワードが必要な場合は、その入力を求めることがあります。これは廃止したSilver Guide独自の保管庫パスワードとは別です。署名済み・読み取り専用・編集禁止など、原本の制限を解除する機能はありません。PDFの保存は、申請の提出・受理ではありません。

### ウェブページのPDFから直接記入する

1. PDFリンクや埋め込みPDFの横の「Silver Guideで記入」を選びます。ファイル選択済みなら「選択したPDFに記入」から開けます。PDFを検出しただけでは取得しません。
2. 添付先が一つに決まれば、そのまま入力を始められます。複数の添付欄や既存ファイルの置き換えがある場合は、欄を選びます。
3. 「戻る／次へ」で記入し、最後の「入力を完了」で記入済みPDFを元の欄へ戻します。手動保存・再添付は不要です。添付欄がなければ通常のPDF保存を使えます。
4. 通常サイトでは添付までを行います。送信操作も行う場合は、上部に表示されたボタン名と「入力完了後に実行する」を選びます。入力不足があれば元フォームへ戻り、確認画面や認証があればその画面で続けます。拡張の「操作を行いました」はサイトの受理を意味しません。

元のページや添付欄・送信先が変わった場合は、PDFの回答を保持して止めます。複数ファイル欄では他の添付を残します。連携できるPDFは20MiBまでです。サイトとPDF配布元へのアクセス権限が必要です。取得できないPDFは、通常のファイル選択・保存を使ってください。

ページ側の専用JavaScriptは不要です。図書館デモの模擬提出は、拡張内のサイト用アダプターで内容確認から完了画面まで進めます。起動方法は[デモの進め方](demo-usability.md)、対応範囲と制約は[設計](decisions/pdf-web-workflow.md)を参照してください。

## 作業を終える前に

PDF原本・回答・修正は、開いている作業タブのメモリー内だけで保持します。連携時は、元フォームのタブにも選択・記入済みPDFを一時的に保持します。**再読み込み、タブを閉じる、ブラウザーを終了する前に、必要なPDFを保存してください。** その後の作業復元は保証しません。元サイトへ入力した値の保存・確認・送信は、元サイトの仕組みに従います。

3.0.0には、保管庫、下書き保存、作業一覧、履歴、バックアップ、登録情報、別の読書画面、読み上げ、手続きチェックリストはありません。旧版の保存データを勝手に削除したり、暗号化を外して移したりはしません。旧版の保管庫を3.0.0で開くこともできないため、必要な資料は旧版側で取り出してください。

## 確認状況

下線語ポップアップ追加前の3.0.0では、WindowsのFloorp 12.20.2／Gecko 158.0.1の通常ウィンドウで、Microsoft IMEへの実キー入力による変換・確定、PDF標準保存先ダイアログの保存・取消・再試行、保存PDFの再表示と再保存を確認しました。今回の追加を含む版は、その履歴と分けて検証結果を記録しています。実利用者の初見評価、他OS、支援技術、すべてのPDFへの対応、署名一般配布の完了を示すものではありません。最新の証拠と範囲は [実装状況](specs/3.0.0/implementation-status.md) を参照してください。
