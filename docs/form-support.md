# 汎用フォーム支援

Silver Guide は、利用者が開始したページの公開構造を端末内で整理します。未確認の行政サイトでも項目を理解して移動する助けになりますが、制度の条件、資格、正しい記入内容、送信可否は判断しません。

## 項目の理解

ネイティブの `input`、`select`、`textarea` を対象にします。項目名は `aria-labelledby`、`aria-label`、関連する `label` の順に確認し、名前がない旧式フォームでは表の行見出しや `dt` / `dd` の関係を使います。項目名が見つからない場合は、その旨を表示します。機械向けの `name` 属性を記入内容として案内しません。

必須属性、`aria-required`、入力の種類、文字数の指定、最小・最大値、`aria-describedby` の説明、ページの入力例を整理します。正規表現を独自に解釈して制度の記入規則に置き換えることはありません。入力エラー文には入力値が含まれることがあるためコピーしません。編集領域、選択肢、計算結果、live region の文字も説明として取り込みません。

## 利用者の操作で進む

- 最初の入力項目へ、前の項目へ、次の項目へ移動します。表示位置は入力済み件数を表すものではありません。
- 前後移動は同じ `form` または `role=form` 内に限定し、`form` 属性で外部から関連付けられた欄も含みます。同じ名前のラジオグループは一つの項目として扱います。
- 送信・リセット・ボタン・パスワード欄、無効・読み取り専用・非表示・非アクティブの欄、通常のフォーカス順から外された欄は案内しません。チェックやファイル選択は利用者自身の操作に委ねます。
- ページが `aria-current=step` で現在の手順を示す場合は、その公開表示を案内します。項目数から手順や完了率は推測しません。
- 最後の項目では、次画面への移動や送信はページのボタンをご自身で確認するよう伝えます。Silver Guide はページの操作ボタンを押しません。

## エラーからの復帰

ページが `aria-invalid` を設定した欄と、ブラウザの `invalid` イベントで通知された欄だけを候補にします。「最初のエラー項目へ」はフォーカスを移すだけです。`checkValidity`、`reportValidity`、値の読み取りによる検証は行いません。

`invalid` イベント由来の通知は、その欄の入力・変更操作でいったん外します。修正済みとの判定ではありません。ページの `aria-invalid` が残っている場合は引き続き案内します。CSS の色や独自クラスだけで示すエラー、項目と結び付かないサーバーエラーは自動判定しません。

## 動的な画面と表示

本文や項目の差し替え、説明・必須・無効・非表示などの属性変更をまとめて再解析します。前画面の欄を残して隠すフォームでも、隠れた欄・用語・見出しを現在の案内に使いません。確認済みガイドは、その時点の URL と表示中の見出しで再判定します。

ページの入力欄にフォーカスがあるときは再描画で奪いません。支援内のボタン・公式リンク・チェックリストにフォーカスがある場合は、その位置を復元します。項目が変わったときは支援内のスクロールを戻し、見出しから読めるようにします。デスクトップでは欄の横か上下の空いている場所へ支援面を置き、狭い画面では高さを抑えた下部シートにします。空きが少ない画面では「表示を小さくする」も利用してください。

用語の追加は公開本文に限定します。フォームのラベル、カスタム入力部品、編集領域、通知・エラー表示は書き換えません。停止時には自分が追加した用語だけを外し、監視・イベント・予約された更新も解除します。

## 対応範囲と制約

| 構造・操作 | 対応 |
| --- | --- |
| 通常のネイティブフォーム、ARIA の名前・説明、表・定義リスト | 共通の項目案内 |
| 同じページ内での動的な欄追加・属性変更・手順差し替え | 再解析して案内を更新 |
| ページが明示した手順・項目エラー | 公開状態の表示と利用者による移動 |
| 確認済み URL と表示中の見出しが一致するガイド | 同梱された制度説明・公式導線 |
| ページ再読み込み、通常の別ページへの遷移 | 新しいページで支援を開始し直す |
| DOM・フォーカス変化を伴わない `history.pushState` | 次の状態照会・フォーカス・DOM 更新で再判定。即時更新はしない |
| iframe、サイト内の Shadow DOM、独自の入力ウィジェット、PDF、ブラウザの保護されたページ | 自動操作や保護の回避をしない。汎用フォーム解析の対象外 |
| 独自エラー表示、極端に狭い表示域、非常に大きな DOM | サイトごとの追加検証が必要 |

入力値・選択状態・添付内容の取得、保存、送信は行いません。設定以外の利用データも保存しません。外部 AI や辞書 API は使用せず、製品の権限は `activeTab`、`scripting`、`storage` のままです。
