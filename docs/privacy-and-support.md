# Silver Guide 3.0.0 プライバシー、権限、問い合わせ

更新日：2026-10-20。対象は未署名の開発版です。正式対応・一般公開の判定は、[3.0.0の実装計画](specs/3.0.0/implementation-plan.md)を参照してください。

## 読み取る情報と処理

フォーム補助は、フォーカス中の欄の公開ラベル・説明・入力形式を使います。入力値を別の回答として取得・複製・保存せず、元欄の値を自動変更したり送信したりしません。

単語の解説は、許可済みページの公開本文を端末内で同梱辞書と照合し、対応する語に下線を付けます。下線語を押すと、その言葉と短い説明をページ内ポップアップに表示します。元のリンク・ボタン・フォーム欄とラベル・パスワード欄・編集領域・コードには解説操作を追加しません。フォーム内の公開本文は対象にできますが、入力値を読み取りません。本文を外部へ送信したり、全文を解説結果として保存したりしません。

補助のサイドパネルは、本人が範囲選択した公開文章を使い、同梱辞書と原文に基づいて端末内で処理します。入力欄や編集領域の中身は取り込みません。対象タブとページを照合し、別のタブやウィンドウの文章を混ぜない設計です。

PDFの読み取り・文字認識・記入・出力検査も、同梱のプログラム、モデル、フォントで端末内処理します。書類・文章・回答を外部AIや解析サービスへ送る機能、自動診断送信、内容を含む診断ログは提供しません。元サイトの通信や、本人が出典リンクを開いた際の通信は、そのサイトとブラウザーの仕組みに従います。

## 作業中の保持と保存

| 情報 | 扱い |
| --- | --- |
| 元フォームの入力値 | 元サイトの欄に保持します。保存・送信は元サイトの操作と仕組みに従います |
| Tooltip | フォーカス中の欄に付く一時表示です。欄を離れるかEscapeで閉じます |
| 下線・単語ポップアップ・選択した文章と解説 | 対象ページに結び付く一時状態です。ポップアップは閉じる・Escape・外側クリックで閉じます。終了後の復元を保証しません |
| PDF原本・回答・修正 | 開いている作業タブのメモリー内だけで保持します |
| 本人が「PDFを保存」で書き出すファイル | 本人が選んだ保存先へ保存します。ブラウザーのダウンロード履歴にも記録される場合があります |

**作業タブの再読み込み・終了、ブラウザー終了後は、未出力のPDF回答を復元できません。** 戻る・修正・出力失敗の間は同じタブで回答を保持しますが、作業を終える前に必要なPDFを保存してください。

書類・本文・回答を拡張機能のストレージ、履歴、バックアップへ自動保存しません。保管庫や下書き機能を廃止した代わりに、平文保存を行うこともありません。ブラウザー自体の履歴・キャッシュ、元サイトが保持する情報、保存済みファイルの扱いは別です。

通常とプライベートの作業を混ぜない設計です。プライベートウィンドウでの拡張機能の使用可否は、ブラウザー標準の許可に従います。プライベートでも、本人が保存したPDFは保存先に残ります。

## 必要な権限

| ブラウザーに表示される権限 | 使用目的 |
| --- | --- |
| HTTP(S)サイトへのアクセス | 許可済みの通常ページで、フォーム補助、公開本文の辞書語の下線とポップアップ、選択文章の解説を行います |
| activeTab（操作したタブへの一時的なアクセス） | 拡張アイコンを押した対象タブへ、一時的にアクセスします。継続的なサイト許可とは別です |
| downloads（ダウンロード） | 本人が操作したPDFの保存と、完了・中断の確認に使います |
| sidePanel（Chromium系） | ブラウザーのサイドパネルへ解説を表示します。Floorp系はブラウザーのサイドバー機能を使います |

サイトアクセスの許可・拒否・取り消しは、ブラウザー標準の拡張機能設定から変更できます。未許可のサイトでは、自動の補助は動きません。アイコン操作による一時許可が可能か、どの範囲で続くかはブラウザーに従います。ブラウザー内部の設定ページなど、許可しても支援できないページがあります。

フォーム補助と下線語の解説ポップアップのために、サイドパネルを開く必要はありません。アクセス許可のための独自アカウント、パスワード登録、欄ごとの開始操作もありません。

## 旧版の保存データとパスワード

3.0.0は、独自の保管庫・パスワード・ロック・永続下書き・履歴・バックアップ・登録情報を提供しません。旧版の保存済みデータを無断で削除・復号・平文変換する処理も行いません。

旧版の保管庫を3.0.0で開く機能はありません。必要な書類は旧版側で取り出してください。保存済みのPDFやバックアップ、本人が複製したファイルは別に残るため、不要になったファイルの削除は本人が行います。

原PDF自身のパスワード、署名、読み取り専用や編集禁止の制約は、独自保管庫の廃止とは別です。PDFを開くためのパスワード入力が必要な場合があります。原本の制約を解除したり、すべてのPDFを編集可能にしたりする機能はありません。
