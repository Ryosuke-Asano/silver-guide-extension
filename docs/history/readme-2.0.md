## ビルドと検証

Node.js 24とCorepackを使用します。固定された依存関係と同梱資材を使い、実行時CDNは使用しません。

```powershell
corepack pnpm@10.13.1 install --frozen-lockfile
corepack pnpm@10.13.1 run check
corepack pnpm@10.13.1 run test
corepack pnpm@10.13.1 run build
corepack pnpm@10.13.1 run build:chromium
```

通常のビルドは同梱資材を検証し、`dist/`（Floorp・Firefox）または`dist-chromium/`を生成します。両者は別の出力です。資材を取得し直す場合は[資材とライセンス](../runtime-assets.md)の手順を参照してください。PDFのブラウザーテストにはPlaywrightのChromiumが必要です。

### Floorp・Firefoxで一時読み込み

1. `about:debugging#/runtime/this-firefox`を開く。
2. 「一時的なアドオンを読み込む」から`dist/manifest.json`を選ぶ。
3. ツールバーのSilver Guideで作業を選ぶ。長い作業は専用タブで進める。

現在のGecko IDは開発用の`silver-guide@example.invalid`です。一時アドオンはブラウザー再起動時に読み込み直しが必要です。正式な署名配布物と同じ保管庫識別子になるという保証はありません。必要な下書きは、アドオンを削除・入れ替える前に暗号化バックアップで保護してください。

### Chromium・Edgeで一時読み込み

`chrome://extensions`または`edge://extensions`の開発者モードから、`dist-chromium/`を「展開して読み込み」で選びます。通常利用者向けのストア配布物は未作成です。
